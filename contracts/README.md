# Contracts

The three sources deployed on Ethereum and BNB Chain, at the same addresses. Solidity 0.8.26, optimizer 200 runs, EVM version Paris. Each file is MIT, as its header says.

The verified source on [Etherscan](https://etherscan.io/address/0xB60e34a0edB0f73E83A8704E56141e12618184C1) and [BscScan](https://bscscan.com/address/0xB60e34a0edB0f73E83A8704E56141e12618184C1) is the reference for the bytecode. What each file does, and the other addresses, is in the [repository README](../README.md).

`MacroSwap.sol` also contains the deposit-box code. The implementation address is not a deposit address. Do not send tokens to it.
